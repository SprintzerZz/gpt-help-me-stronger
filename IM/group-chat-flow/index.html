④ 四个容易被面试官追问的点

群级 Redis 锁为什么可能影响 P99？

同群锁覆盖 Redis INCR 分配 seqNo、MySQL 同步 INSERT、Redis 更新最大 messageId。INCR 自身已确保唯一；锁还用于让 seqNo 与 MySQL 自增 ID 的分配顺序保持一致。

Kafka 是给每个群成员发送一条吗？

不是。当前 IMSender 对接收方在线终端按 serverId 分组，每组一包；发送者其他终端逐个另行同步，即使落在同节点也可能产生额外包。

HTTP 返回成功表示所有群成员已收到吗？

不是。Kafka Broker ACK 只说明 Kafka 确认写入，不等于 Channel 写入成功，也不等于客户端送达。群聊结果回程仅记录 SUCCESS 日志或触发离线处理，不使用私聊 cmd=7 送达 ACK。

群消息严格按 seqNo 到达吗？

不能保证。锁只覆盖保存阶段；释放锁后 Kafka 投递可能因调度差异乱序，例如 seq=101 可能先于 seq=100 到达。客户端需要按 seqNo 排序、缺口补拉。
